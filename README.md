# AI-Powered Resume Screener

An intelligent resume screening agent that parses uploaded PDF resumes and uses LangChain + Groq (Llama 3) to generate structured match scores and hiring recommendations.

## Live Demo
[Click here to try the app](https://resume-screener-bxc9bkagkzdfbrvnxkguqy.streamlit.app)

## Features
- Upload any PDF resume and paste a job description
- LLM-powered match scoring with structured recommendations
- Built with LangChain, Groq API, pdfplumber, and Streamlit

## Tech Stack
- Python, LangChain, Groq (Llama 3), pdfplumber, Streamlit

## How to Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
